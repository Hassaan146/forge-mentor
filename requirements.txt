# On the test strategy, since the note here used to claim the model was mocked:
# nothing is mocked, because nothing needs to be. The core logic is state
# files, the governor, routing tables and parsing — all exercised by calling
# the functions directly and by driving real files and real git repositories
# in a temp directory. The MCP surface is checked once against the protocol's
# own tool list. There is no model in the loop to mock, which is exactly what
# makes the suite fast, free and deterministic.
