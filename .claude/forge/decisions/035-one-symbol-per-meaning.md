# Seven, each carrying exactly one meaning — and a frame around every block

**Options considered**

- **A** — keep the four symbols of rule R9 unchanged
- **B** — one symbol per meaning, fixed set, nothing decorative
- **C** — emoji freely wherever they help

**Recommended:** B · **Decided:** B

## What was wrong

Two things, and only one of them was about symbols.

The follow-up text — the part that answers "why not the other option" — was written as plain
prose outside any frame. So a session looked like Forge for one screen and like ordinary chat
for the next, and the visual identity that rule R5 asks for held only while a question was on
screen. It was also long: several paragraphs to restate three costs that the record already
holds.

## The rule this amends

R9 said four symbols, and restraint was the point. That was right about restraint and wrong
about the number: four meant headings had no marker at all, so "What this means", "Options" and
the cost of a recommendation were distinguished by nothing but position.

The rule is now **one symbol per meaning, and no symbol without a meaning**:

| | |
|---|---|
| ⚒ | Forge itself |
| 💡 | what this means — the teaching |
| ⚖️ | options, weighed against each other |
| ★ | the recommendation |
| ⚠️ | what the recommendation costs |
| ✅ | recorded |
| ⛔ | blocked |

Seven, fixed, and none of them decorative. Adding an eighth requires a meaning nothing else
carries — which is the same restraint R9 wanted, expressed as a test rather than a count.

Colour is unchanged and still never the only signal: every one of these reads the same in a
terminal with no colour, because the words beside them carry it.

## The frame

Every block Forge produces goes inside one, including follow-ups. A framed answer is
recognisably Forge; an unframed paragraph is indistinguishable from the assistant talking, and
the user cannot tell which one is bound by the rules.

## Short, and enforced by having somewhere to be short

Follow-ups are capped: three lines of prose, or three bullets. The reason a follow-up sprawled
is that it had no shape to fill — given a frame with a lid on it, the cost of each option fits
in one line, and the full argument stays in the decision record where it belongs.
